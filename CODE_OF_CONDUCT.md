# Community conduct

Be respectful, specific, and constructive. Critique code and ideas, not people.
No harassment, discrimination, threats, doxxing, or publication of another
person's private information. Respect a request to stop an interaction.

Maintainers may edit/remove harmful content, lock discussions, or restrict
participation, proportionate to the conduct and its impact. Good-faith technical
disagreement and clear bug reports are welcome.

For a concern, contact a repository maintainer privately through an available
profile contact. If no private contact is available, ask for one without posting
identifying details or the sensitive report publicly. GitHub platform abuse can
also be reported through GitHub's reporting controls. Vulnerabilities use the
separate process in [SECURITY.md](SECURITY.md).
